# Stack Analyzer — 股票新聞分析工具

搜尋最新新聞與財務數據，自動生成利好/利空分析報告（`.md` + `.html`），支援美股、台股、陸股三市場。

---

## 快速開始

```bash
/stack-ana us:INTC       # 分析美股 Intel
/stack-ana tw:2330       # 分析台股台積電
/stack-ana cn:600519     # 分析陸股貴州茅台
```

---

## 使用格式

```
/stack-ana {market}:{ticker_or_name}
```

| 參數 | 說明 |
|------|------|
| `market` | 市場代碼：`us`（美股）、`tw`（台股）、`cn`（陸股） |
| `ticker_or_name` | 股票代碼或公司名稱 |

### 輸入範例

| 市場 | 代碼輸入 | 名稱輸入（模糊匹配） |
|------|----------|----------------------|
| 美股 | `us:INTC` | `us:intel` |
| 台股 | `tw:2330` | `tw:台積電` |
| 陸股 | `cn:600519` | `cn:茅台` |

> 使用公司名稱時，系統會先搜尋對應代碼並向你確認，確認後才開始分析。

---

## 輸出檔案

報告輸出到 `stackana/` 目錄，依市場分資料夾：

```
stackana/
├── us/          # 美股
│   ├── INTC_2026-04-03.md
│   └── INTC_2026-04-03.html
├── tw/          # 台股
│   ├── 2330_2026-04-03.md
│   └── 2330_2026-04-03.html
└── cn/          # 陸股
    ├── 600519_2026-04-03.md
    └── 600519_2026-04-03.html
```

- 檔名格式：`{代碼}_{YYYY-MM-DD}.md / .html`
- 同日重複分析同一股票會覆蓋舊檔

---

## 報告內容

每份報告包含以下章節：

| 章節 | 說明 |
|------|------|
| 近期重大事件 | 3-5 條最新新聞摘要與影響分析 |
| 財務數據摘要 | 營收、EPS、毛利率、本益比、市值、52 週高低等 |
| 利好 / 利空分析 | 逐條列出因素、判斷（利好/利空/觀望）、分析說明 |
| 總結 | 整體判斷、短期風險、中期催化劑、操作建議 |
| 參考來源 | 新聞連結清單 |

### HTML 報告特色

- 暗色主題，可直接用瀏覽器開啟
- 股價統計卡片（漲跌幅、年初至今、52 週高低）
- 利好/利空彩色標籤（綠色/紅色/黃色）
- 獨立文件，不依賴外部 CSS/JS

---

## 注意事項

- 財務數據以搜尋結果為準，搜尋不到的欄位會標記「—」
- 利好/利空判斷基於具體新聞事件，非泛泛而談
- 本工具依賴 WebSearch，需在有網路的環境下使用
- 報告為即時分析快照，不構成投資建議
