# API Analysis - API 接口分析與同步

分析當前項目功能與已開發的 API 接口，檢查是否需要新增、更新或刪除接口。

## 執行步驟

1. **分析項目當前功能**
   - 掃描項目代碼，識別所有業務功能模組
   - 理解數據模型與業務邏輯的變更

2. **分析已有 API 接口**
   - 讀取現有的 API 路由與控制器代碼
   - 讀取 `/api/support` 端點的元數據（如已存在）
   - 讀取 `.claude/docs/api.readme`（如已存在）

3. **比對差異，生成分析報告**
   - 以表格形式列出分析結果：

   ### 需要新增的接口
   | 接口路徑 | 方法 | 原因 |
   |----------|------|------|
   | | | |

   ### 需要更新的接口
   | 接口路徑 | 方法 | 變更內容 | 原因 |
   |----------|------|----------|------|
   | | | | |

   ### 建議刪除的接口
   | 接口路徑 | 方法 | 原因 |
   |----------|------|------|
   | | | |

   ### 無需變更的接口
   | 接口路徑 | 方法 | 狀態 |
   |----------|------|------|
   | | | |

4. **等待用戶確認**
   - 用戶可對分析結果進行調整
   - 確認無誤後才執行變更

5. **執行變更**
   - 根據確認後的方案，執行新增 / 更新 / 刪除操作
   - 同步更新 `/api/support` 端點的元數據

6. **更新 API 文檔**
   - 自動將變更同步到 `.claude/docs/api.readme`
   - 確保文檔與當前接口狀態一致

7. **總結**
   - 列出本次變更統計（新增 / 更新 / 刪除數量）
   - 確認文檔已同步更新
