# API Docs - API 接口文檔生成

分析當前項目的所有 API 接口，生成完整的接口文檔到 `.claude/docs/api.md`。

## 執行步驟

1. **掃描所有 API 接口**
   - 讀取項目中的路由定義與控制器代碼
   - 讀取 `/api/support` 端點的元數據（如已存在）
   - 識別所有已實現的 API 端點

2. **提取接口資訊**
   - 對每個接口提取：
     - 路徑（Path）
     - HTTP 方法（GET / POST / PUT / DELETE 等）
     - 功能描述
     - 請求參數（Query / Body / Path params）
     - 請求範例
     - 回應格式與範例
     - 錯誤碼說明
     - 認證需求（如有）

3. **生成文檔**
   - 將文檔寫入 `.claude/docs/api.md`
   - 使用以下格式：

   ```markdown
   # API 接口文檔
   ## 版本: x.x.x
   ## 最後更新: YYYY-MM-DD
   ## Base URL: http://localhost:port/api

   ---

   ## 目錄
   - [模組名稱](#模組名稱)

   ---

   ## 模組名稱

   ### 接口名稱
   - **路徑**: `/api/xxx`
   - **方法**: `GET`
   - **描述**: 功能描述
   - **認證**: 是否需要

   #### 請求參數
   | 參數名 | 類型 | 必填 | 說明 |
   |--------|------|------|------|
   | | | | |

   #### 請求範例
   ```json
   {}
   ```

   #### 回應範例
   ```json
   {}
   ```

   #### 錯誤碼
   | 狀態碼 | 說明 |
   |--------|------|
   | | |
   ```

4. **確認輸出**
   - 確保 `.claude/docs/` 目錄存在，不存在則創建
   - 寫入文檔後告知用戶文檔路徑與接口總數
