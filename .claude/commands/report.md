# Project Status Report

生成當前專案的完整狀態報告。

## 執行步驟

1. **Git 狀態分析**
   - 取得當前分支：`git branch --show-current`
   - 取得未提交的變更：`git status`
   - 取得最近 10 筆 commit 記錄：`git log --oneline -10`
   - 檢查是否有未合併的分支

2. **專案結構概覽**
   - 掃描專案根目錄的主要資料夾與文件
   - 識別使用的語言與框架（從 package.json、requirements.txt、*.csproj 等判斷）
   - 統計文件數量與主要檔案類型

3. **進度狀態**
   - 讀取 `.claude/session.md`（如果存在），摘要當前進度
   - 列出待辦事項與已完成項目

4. **問題與建議**
   - 檢查是否有未處理的 TODO / FIXME 註釋
   - 檢查是否有明顯的代碼問題（大文件、缺少錯誤處理等）
   - 提出改進建議

5. **輸出報告格式**

```markdown
# 專案狀態報告
## 報告日期: YYYY-MM-DD

### Git 狀態
- 當前分支: xxx
- 未提交變更: N 個文件
- 最近活動: <摘要>

### 專案概覽
- 語言/框架: xxx
- 主要模組: xxx

### 進度
- 狀態: [進行中 | 已完成 | 阻塞]
- 已完成: N 項
- 待辦: N 項

### 問題與建議
- <問題/建議列表>
```
