# Stack Analyzer — 股票新聞分析與報告生成

根據用戶輸入的市場代碼與股票代碼，搜尋最新新聞與財務數據，生成利好/利空分析報告，輸出 `.md` + `.html` 到對應市場目錄。

## 使用方式

```
/stack-ana {market}:{ticker_or_name}
```

## 參數解析

收到的參數為：`$ARGUMENTS`

### 格式規則

| 市場 | 前綴 | 範例 | 輸出目錄 |
|------|------|------|----------|
| 美股 | `us:` | `us:INTC`、`us:intel` | `stackana/us/` |
| 台股 | `tw:` | `tw:2330`、`tw:台積電` | `stackana/tw/` |
| 陸股 (A股) | `cn:` | `cn:600519`、`cn:茅台` | `stackana/cn/` |

- 若參數為空，顯示上方使用說明表格
- 若參數缺少市場前綴，提示用戶補上（例如輸入 `INTC` 應提示 `請指定市場，例如 us:INTC`）

### 模糊匹配

用戶可能輸入公司名稱而非代碼（如 `us:intel`、`tw:台積電`、`cn:茅台`）。處理方式：

1. 先嘗試將輸入視為股票代碼直接搜尋
2. 若輸入為英文/中文名稱（非純數字且非全大寫英文短碼），用 WebSearch 搜尋 `"{name}" stock ticker symbol` 或 `"{name}" 股票代碼` 來解析正確代碼
3. 解析出代碼後，向用戶確認：「查詢到 {公司名} ({代碼})，是否正確？」
4. 確認後再進入分析流程

---

## 執行流程

### Step 1：解析參數與確認標的

1. 解析 `$ARGUMENTS`，拆分 `market` 和 `ticker`
2. 若為模糊名稱，執行模糊匹配（見上方規則）
3. 確定最終的：市場代碼、股票代碼、公司全名

### Step 2：搜尋新聞與數據

根據市場使用不同語言搜尋：

| 市場 | 搜尋語言 | 搜尋關鍵字範例 |
|------|----------|----------------|
| 美股 `us` | **英文** | `"{company}" OR "{ticker}" stock news {year}` |
| 台股 `tw` | **中文** | `"{公司名}" 股票 最新新聞 {year}` |
| 陸股 `cn` | **中文** | `"{公司名}" 股票 最新消息 {year}` |

執行兩次 WebSearch（並行）：
- **新聞搜尋**：搜尋最新新聞事件
- **財務搜尋**：搜尋最新財報數據、營收、EPS、本益比等

### Step 3：分析與撰寫報告

**報告語言：統一使用繁體中文**（即使美股搜尋結果為英文，報告仍以中文撰寫）

報告結構如下：

```markdown
# {公司名} ({代碼}) 股票分析報告

> 分析日期：YYYY-MM-DD | 市場：{市場名稱} | 收盤價：{價格}

---

## 一、近期重大事件
（列出 3-5 條近期重要新聞，每條包含標題、摘要、影響）

## 二、財務數據摘要
| 指標 | 數值 | 同比變化 |
|------|------|----------|
| 最近季度營收 | | |
| EPS | | |
| 毛利率 | | |
| 本益比 (P/E) | | |
| 市值 | | |
| 52 週高/低 | | |

（根據搜尋到的數據填入，未找到的標記為「—」）

## 三、利好 / 利空分析
| 因素 | 判斷 | 分析 |
|------|------|------|
（利好標記為 **利好**，利空標記為 **利空**，不確定標記為 **觀望** 或 **中性**）

## 四、總結
- 整體判斷（利好/利空/中性）
- 短期風險
- 中期催化劑
- 操作建議

## 參考來源
- [來源標題](URL)
```

### Step 4：生成 HTML

基於 Markdown 內容生成獨立 HTML 文件，使用**暗色主題**：

#### 設計規範
- 背景色：`#0f1117`，卡片：`#1a1d28`，邊框：`#2a2d3a`
- 利好標籤：綠色 `#22c55e`
- 利空標籤：紅色 `#ef4444`
- 觀望/中性標籤：黃色 `#eab308`
- 強調色：`#818cf8`
- 頂部顯示股價統計卡片（漲跌幅、年初至今、52 週高低等）
- 事件用 `.card` 卡片展示
- 利好/利空表格用彩色 `.tag` 標籤
- 總結用漸層邊框的 `.summary-box`
- 底部包含參考來源連結
- 頁尾：`Generated by Claude Code Stack Analyzer | YYYY-MM-DD`

### Step 5：輸出文件

1. 確認目錄存在（`stackana/{market}/`），不存在則建立
2. 輸出兩個文件：
   - `stackana/{market}/{TICKER}_{YYYY-MM-DD}.md`
   - `stackana/{market}/{TICKER}_{YYYY-MM-DD}.html`
3. 台股代碼用數字（如 `2330_2026-04-03.md`）
4. 陸股代碼用數字（如 `600519_2026-04-03.md`）
5. 美股代碼用大寫英文（如 `INTC_2026-04-03.md`）

### Step 6：完成摘要

輸出簡短摘要：

```
報告已生成：
- MD: stackana/{market}/{TICKER}_{date}.md
- HTML: stackana/{market}/{TICKER}_{date}.html

{公司名} ({代碼}) — 整體判斷：{利好/利空/中性}
關鍵要點：{一句話總結}
```

---

## 注意事項

- 所有報告內容使用**繁體中文**
- 財務數據以搜尋結果為準，搜不到的欄位標記「—」，不可編造數字
- 利好/利空判斷需基於具體新聞事件，不可空泛
- HTML 為獨立文件，不依賴外部 CSS/JS，可直接瀏覽器開啟
- 若同日已有同一股票的報告文件，覆蓋舊文件
