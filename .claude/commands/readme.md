# Update README

更新目前項目的使用手冊 `README.md`。

## 執行步驟

1. 讀取現有的 `README.md`（若存在）
2. 掃描專案目錄結構，識別：
   - 主要技術棧與框架
   - 入口文件與關鍵模組
   - 配置文件（`.env.example`、`config/` 等）
   - 已定義的 scripts / commands
3. 讀取 `CLAUDE.md` 及對應的 profile 文件，取得：
   - 專案類型與技術棧資訊
   - 自定義命令清單
   - 目錄結構約定
4. 根據蒐集到的資訊，生成或更新 `README.md`，包含以下章節：

```markdown
# <專案名稱>

<簡短描述>

## 技術棧
- <框架 / 語言 / 版本>

## 安裝步驟
1. <clone / 安裝依賴 / 環境設定>

## 啟動方式
```bash
<啟動指令>
```

## 環境變數說明
| 變數名 | 說明 | 預設值 |
|--------|------|--------|
| | | |

## 目錄結構
```
<專案目錄樹>
```

## 常用命令
| 命令 | 說明 |
|------|------|
| | |
```

5. 若 `README.md` 已存在，保留用戶手動撰寫的自定義章節，僅更新可自動偵測的部分
6. 完成後告知用戶 README 已更新，並簡要摘要變更內容
