# Obsidian 未完成任務篩選

將指定的 Obsidian Markdown 檔案中未完成的任務篩選出來，打印到 console。

## 參數

- `$ARGUMENTS` — 要掃描的 Obsidian Markdown 檔案路徑

## 執行步驟

1. **讀取檔案**
   - 讀取 `$ARGUMENTS` 指定的 Markdown 檔案
   - 如果檔案不存在，提示錯誤並終止

2. **掃描任務項目**
   - 識別所有未完成的任務行：
     - `- [ ]` — 未開始
     - `- [/]` — 進行中
   - 忽略已完成 `- [x]` 和已取消 `- [-]` 的任務

3. **收集上下文資訊**
   - 記錄每個任務所屬的最近父級標題（`##`、`###` 等）
   - 識別任務附帶的元資訊：
     - 截止日期：`📅 YYYY-MM-DD`
     - 高優先級：`⏫`
     - 中優先級：`🔼`
     - 低優先級：`🔽`
     - 開始日期：`🛫 YYYY-MM-DD`
     - 排程日期：`⏳ YYYY-MM-DD`

4. **分組排序**
   - 按優先級分組：⏫ 高優先級 → 🔼 中優先級 → 一般（無標記）→ 🔽 低優先級
   - 同組內按截止日期升序排列（無日期的排在後面）

5. **輸出到 console**
   - 格式如下：

```markdown
# 未完成任務 — <檔案名稱>
## 掃描時間: YYYY-MM-DD HH:MM

### ⏫ 高優先級
- [ ] 任務內容 📅 2026-03-01
  └─ 來源章節: ## 章節名稱

### 🔼 中優先級
- [ ] 任務內容
  └─ 來源章節: ## 章節名稱

### 一般
- [ ] 任務內容
- [/] 進行中的任務
  └─ 來源章節: ## 章節名稱

### 🔽 低優先級
- [ ] 任務內容
  └─ 來源章節: ## 章節名稱

---
合計: X 個未完成 | X 個進行中
```

6. **邊界情況處理**
   - 如果檔案中沒有任何未完成任務，輸出「✅ 沒有未完成的任務」
   - 如果任務不在任何標題下，來源章節顯示為「（文件頂層）」
