# Obsidian 已完成任務篩選

將指定的 Obsidian Markdown 檔案中已完成的任務篩選出來，打印到 console。

## 參數

- `$ARGUMENTS` — 要掃描的 Obsidian Markdown 檔案路徑

## 執行步驟

1. **讀取檔案**
   - 讀取 `$ARGUMENTS` 指定的 Markdown 檔案
   - 如果檔案不存在，提示錯誤並終止

2. **掃描任務項目**
   - 識別所有已完成的任務行：
     - `- [x]` — 已完成
   - 忽略未完成 `- [ ]`、進行中 `- [/]` 和已取消 `- [-]` 的任務

3. **收集上下文資訊**
   - 記錄每個任務所屬的最近父級標題（`##`、`###` 等）
   - 識別任務附帶的完成日期：`✅ YYYY-MM-DD`

4. **排序**
   - 按完成日期降序排列（最近完成的在前）
   - 無完成日期的排在後面
   - 同日期按檔案中出現的順序排列

5. **輸出到 console**
   - 格式如下：

```markdown
# 已完成任務 — <檔案名稱>
## 掃描時間: YYYY-MM-DD HH:MM

### 已完成
- [x] 任務內容 ✅ 2026-02-25
  └─ 來源章節: ## 章節名稱
- [x] 任務內容 ✅ 2026-02-20
  └─ 來源章節: ## 章節名稱
- [x] 任務內容
  └─ 來源章節: ## 章節名稱

---
合計: X 個已完成
```

6. **邊界情況處理**
   - 如果檔案中沒有任何已完成任務，輸出「📭 沒有已完成的任務」
   - 如果任務不在任何標題下，來源章節顯示為「（文件頂層）」
