# Save Session Progress

將當前 session 的進度寫入 `.claude/session.md`。

## 執行步驟

1. 取得當前 git 分支名稱：`git branch --show-current`
2. 取得當前日期時間
3. 回顧本次 session 的對話內容，整理出：
   - 當前正在進行的任務
   - 已完成的步驟
   - 下一步計劃
   - 遇到的問題或阻塞點
   - 重要的決策記錄
4. 將整理後的內容寫入 `.claude/session.md`，使用以下格式：

```markdown
# Session 進度記錄
## 狀態: [進行中 | 已完成 | 阻塞]
## 最後更新: YYYY-MM-DD HH:MM
## 當前分支: <branch_name>

### 當前任務
- <描述正在進行的工作>

### 已完成
- [x] <已完成項目>

### 待辦
- [ ] <下一步>

### 決策記錄
| 日期 | 決策 | 原因 | 替代方案 |
|------|------|------|----------|
| | | | |

### 已知問題
- <問題描述> — <狀態>
```

5. 完成後告知用戶進度已儲存，並簡要摘要儲存的內容
