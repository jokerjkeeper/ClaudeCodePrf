# Conversation Summary — 對話歸檔與載入

智能判斷保存或載入對話記錄。同一個指令，根據檔案是否存在自動切換行為。

## 參數

- `$ARGUMENTS`：檔案標題關鍵字（英文小寫，用底線連接），例如 `math1`、`arch_design`、`perf_tuning`

## 執行步驟

1. 確認 `.claude/conv/` 目錄存在，不存在則建立
2. 根據參數決定檔案名稱：`.claude/conv/conv_{$ARGUMENTS}.md`
   - 若未提供參數，從對話內容自動提取一個簡短的英文關鍵字作為標題
3. **檢查檔案是否已存在**：

### 模式 A：檔案不存在 → 保存當前討論

回顧本次 session 的對話內容，整理出：
- 討論的主題與背景
- 關鍵結論與決策
- 重要的技術細節或發現
- 後續行動建議（如有）

將整理後的內容寫入檔案，使用以下格式：

```markdown
# {主題標題}

> {一句話摘要}
> 記錄日期：YYYY-MM-DD

---

## 一、背景與問題

- {討論的起因或問題描述}

## 二、關鍵結論

- {重點歸納，條列式}

## 三、技術細節

{視內容需要，可包含代碼片段、架構說明、比較表格等}

## 四、後續行動

- [ ] {待辦事項}（如有）
```

完成後告知用戶內容已儲存，並顯示檔案路徑與簡要摘要。

### 模式 B：檔案已存在 → 載入並繼續討論

1. 讀取 `.claude/conv/conv_{$ARGUMENTS}.md` 的完整內容
2. 向用戶摘要該檔案的重點：主題、關鍵結論、待辦事項
3. 詢問用戶要繼續討論哪個部分，或是否有新的進展需要補充
4. 進入討論模式，準備接續之前的對話脈絡
